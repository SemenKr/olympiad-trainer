# Progress Evidence v0

The checkpoints for `guaranteed-sock-pair` and `table-impossible-sums` have two explicit factual buckets. The browser-local `olympiad-trainer:progress-evidence-v0` value is a legacy source imported once into [Server-backed Learner Persistence v1](server-backed-learner-persistence.md). New contributing Finish transactions update PostgreSQL. The first bucket supports `Как гарантировать результат`; the second supports `Доказывать, что что-то невозможно`.

Each bucket retains three facts: the latest correct checkpoint without earlier hints, the latest correct checkpoint with earlier hints, and the latest incorrect checkpoint. Each contribution receives the next positive sequence number within its bucket; replacing one slot leaves the other two intact. A fact contains only the fixed problem ID, the checkpoint observation, ordered hint levels exposed before submission, and `solutionExposedBeforeCheckpoint: false`. No answer draft, protected prompt or options, interpretation, score, or mastery state is stored. The existing version 1 guarantee-only shape remains readable; the first table contribution migrates it to a version 2 wrapper with both explicit buckets.

The original browser-local Finish used a Practice-specific pending transition record across unfinished, latest-completed and Progress keys. In v1, new contributions are appended to PostgreSQL before local Summary finalization; a local pending record still protects retry and recovery of that finalization.

The server validates exact snapshot shapes and sequence constraints on import and read, and rechecks every retained option and outcome against the canonical server-only checkpoint checker. Invalid or unverifiable reads do not mutate storage, and `/progress` shows an error rather than an empty state; a failed import leaves browser-local bytes available for retry. Interpretation is derived only on verified read. Both groups are capped at `Начинаю разбираться`; repeated structured recognition of either checkpoint does not establish independent proof construction, transfer, reliability, or mastery. Incorrect-only evidence creates no weakness label, and later incorrect evidence does not erase an earlier positive fact.
