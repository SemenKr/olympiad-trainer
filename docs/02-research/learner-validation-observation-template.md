Keep facts and explanations separate.

Examples of useful facts:

- “On Home, learner selected X before speaking.”
- “After an incorrect answer, learner looked at the page for 20 seconds and selected Back.”
- “Learner asked ‘Где подсказка?’ before the observer said anything.”
- “Parent pointed to the Finish button; learner then completed the session.”

Avoid labels such as “inattentive”, “weak at maths” or “did not understand anything”.

## Scenario coverage

### Home

- What did the learner do first?
- Did they understand the primary next action?
- Was any navigation help required?

### Practice

- Could they enter and check an answer?
- What happened after incorrect feedback?
- Did retry behavior make sense?
- Was help discovered naturally?
- Did hint vs full solution appear distinct?
- Was Skip encountered? If yes, what did the learner expect?
- Was any UI assistance required?
- Was any mathematical assistance required?

### Pause / resume

- What did the learner expect to be preserved?
- What actually remained?
- Was recovery understandable?

### Finish / Summary / Progress

Record the learner's own paraphrase before explaining anything.

- What did Summary mean to them?
- What did Progress mean to them?
- What did XP mean to them?
- Did any element sound like a grade, mastery score or diagnosis?

### Simulation

Use only in a separate Simulation visit.

- Did the learner understand 4 tasks / 45 minutes?
- Did drafts and task navigation make sense?
- Did they understand that leaving does not pause the timer?
- Did Finish feel irreversible?
- Did references after Finish make sense?
- Was any work lost or shown as submitted unexpectedly?

## Parent-observed remote intake

When a parent sends an unstructured report, preserve the raw message outside the repository, then normalize only supported facts into this template.

Minimum useful return from a parent:

- device;
- broad olympiad familiarity;
- first action on Home;
- where the child became unsure;
- where adult help was needed;
- unclear buttons, feedback, help, Finish, Summary or Progress;
- short verbatim learner phrases where available;
- what felt convenient;
- where the learner expected a different result;
- whether the learner wanted to return.

Do not turn absence of a comment into evidence that a flow worked.
