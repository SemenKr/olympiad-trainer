## Scope and evidence

All 60 registered definitions were read: statements, expected responses/options, provenance, three hints, full solutions and optional checkpoints. Static inventory was cross-checked against the registered Packs; no application code or learner data was changed. Source links/pages below are **catalog provenance**, not a claim that every original PDF was freshly reopened or every derivation independently certified. Historical source/adaptation review lives in [initial audit](problem-content-audit.md), [J–L dossier](content-scale-v2-batch-2.md), [M–O dossier](content-expansion-batch-1.md) and [P–R dossier](content-expansion-batch-2.md). Earlier entries also require their code/source comparison; a dossier is not a permission grant.

Observed inventory: **60 problems, 18 ordered Packs of 3, 54 distinct Pack problems, 6 outside Packs; 49 nonnegative-integer and 11 multiple-choice-set assessments; 180 hints; 60 solutions; 5 checkpoint-bearing problems; no authored statement media**. All 60 provenance records name Moscow, Grade 5 mathematics. This is source selection, not national representativeness. Code links pin the inspected revision.

Evidence/confidence for every row: **E=H** for observed code fields, access path and support; **T=M** for provisional semantic mapping of the displayed authored solution path; **V=open** for independent human mathematical/source-correspondence and rights approval. These are separate judgments, not probabilities or learner scores. Mapping does not claim the only valid method, independent use by a learner, or mastery. A capability listed in a solution may be supplied by a hint rather than demanded by the input field.

## Reading the matrix

Aliases below are local table abbreviations for the existing [Skill Taxonomy v0.1](skill-taxonomy-v0.1.md), **not new taxonomy IDs, skills or software fields**. Primary concept family is assigned once per row for a reproducible descriptive tally; specific secondary concepts remain in the row. Counts are not targets or difficulty labels.

- Q quantities / operations; N number properties; G geometry / measurement; O order / structure; L logical relations; C counting / selection. These reuse the taxonomy's concept families, not a complete concept standard.
- FN = Формулировать логические отрицания; FQ = Переводить количественные связи в выражения и уравнения.
- C = Согласовывать несколько ограничений; E = Исключать несовместимый вариант по нарушенному условию; S = Систематически перебирать случаи и обосновывать полноту; W = Строить и проверять допустимую конфигурацию.
- B = Устанавливать границы величины при ограничениях; O = Доказывать оптимальность через границу и свидетельство достижимости; G = Обосновывать гарантированный результат при неблагоприятном выборе; I = Доказывать глобальную невозможность через ограничения.
- Methods retained in v0.1: A = Разбор случаев; X = Противоречие; K = Конструкция; P = Периодичность. Provisional methods: R = Декомпозиция и перестроение; H = Рассуждение от худшего случая; D = Принцип Дирихле; J = Однозначное соответствие. A dash means no normalized method confidently assigned, not absence of reasoning. Double counting, cancellation, recursive reduction and greedy choice are descriptive strategies here; they are not silently added to the taxonomy.

Family, method and capability columns have separate namespaces. N/S in the response column means numeric/set; +CP marks an authored checkpoint. Neither final-answer type directly captures an open proof, drawing or free construction. A checkpoint samples a bounded reasoning choice; it does not certify the entire proof.
