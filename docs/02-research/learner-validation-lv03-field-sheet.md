# LV-03 — полевой лист наблюдателя

Task: OT-LV03-FIELD-01. Пустой бланк для печати; ориентир сессии — 20–40 минут, можно закончить раньше. Следуйте [Learner Validation v0](learner-validation-v0.md); этот лист сокращает запись, а не заменяет протокол. Заполненный лист храните вне репозитория.

## 1. Сначала обычная Practice

Открытие: «Мы проверяем приложение, а не тебя. Если что-то непонятно, это полезно для проверки приложения. Можно остановиться в любой момент».

Вход: «У тебя есть немного времени позаниматься олимпиадной математикой. Покажи, что бы ты сделал». Затем: «Решай так, как обычно. Можно пользоваться тем, что предлагает страница».

Не объяснять интерфейс заранее и не заставлять ошибаться, открывать помощь, решение или Skip. Наблюдать ввод → проверку → следующую попытку/действие. После **естественно использованной помощи** спросить один раз: **«Что ты теперь попробуешь сделать?»** Дать действовать без подсказки метода. Если помощь не использована, отметить это; не создавать эпизод ради заполнения листа.

**Эпизод помощи** (повторить на обороте при необходимости):

- Вмешательство наблюдателя — отдельно: нет / UI / математическое; точные слова/действие и момент: _______________________________________________________
- Что произошло после вмешательства: __________________________________________

## 2. Foundations A/B — только по желанию и при уместности

Проводить после обычного наблюдения в естественной паузе или другой встрече; не прерывать незавершённое рассуждение. Если ученик устал или отказался, пропустить.

[Протокол и объяснение A/ключ B — только наблюдателю](olympiad-foundations-prototype-v0.1.md). [Карточки ученика](olympiad-foundations-learner-cards-v0.1.md) показывать по одной, без ключей. Проверка содержания человеком перед использованием подтверждена: да / нет; версия и ссылка на подтверждение без личных данных: _______________. Если нет — пропустить A/B, обычная Practice остаётся доступной.

Предложение: «Хочешь попробовать две короткие задачи? Можно решать любым способом, пропустить задачу или остановиться».

Проведено: да / нет · Причина проведения/пропуска: ____________________________

**A:** первая идея/действие и метка: ___________________________________________

Слова, проверки условий, вмешательство взрослого: ____________________________

Объяснение A просмотрено: да / нет / частично. Просьба/выбор ученика, момент: ____

Предлагать объяснение по протоколу только при естественном запросе помощи или желании сравнить после попытки; показывать по явному согласию. После просмотра: «Что ты теперь попробуешь сделать?» Слова / действие / помощь отдельно: ______

**B:** хочет продолжить: да / нет. Убрать A и её объяснение. «Попробуй решить эту задачу так, как тебе удобно». Не напоминать метод; при затруднении записать запрос помощи и предложить остановиться или обсудить после попытки.

- Первое действие до обсуждения / метка: _______________________________________
- Какие условия реально проверял; пример принятого/отвергнутого варианта и причина: ___________________________________________________________________
- Полнота: как объяснил отсутствие других вариантов; пропуски/повторы, если видны: ___________________________________________________________________
- Сказал сам (С) / после вопросов (П) «Как ты проверял свои варианты?» и «Как ты решил, что других вариантов нет?» / с помощью (А): _________________________
- Вмешательство взрослого отдельно; объяснение B увидел ли и когда: ____________
- Усталость / Skip / отказ / остановка и причина со слов ученика: ______________

Необязательно использовать таблицу. Если объяснение полноты не прозвучало, записать «не наблюдалось». **B — близкое повторное применение; это не свидетельство независимого переноса.** После объяснения A работа B идёт в контексте предшествующего обучения.

## 3. После сессии — короткий синтез

Факт и дословная фраза: ______________________________________________________

Гипотеза причины / альтернативное объяснение: ________________________________

| Возможное направление | Наблюдение, которое его поддерживает |
| --- | --- |
| Wording fix | Перефразирование без новой математической идеи позволило продолжить. |
| Knowledge Support | План понятен, но конкретное базовое понятие/операция мешает действовать. |
| Bounded Foundations proposal | Понятный текст не помог начать; отдельный пример предшествовал собственной следующей попытке на B. Нужны подтверждение и альтернативные объяснения. |
| No change | Ученик продолжает осмысленно; дополнительное объяснение не требуется или мешает. |
| Insufficient evidence | Не хватает слов/действий, сильное вмешательство, усталость или противоречивые наблюдения. |

Выбранное направление / факт-основание / что проверить следующим: _____________

Severity: Critical / Major / Minor / observation. Critical — остановить затронутый сценарий; воспроизводимые Major приоритетны. По [существующему правилу](learner-validation-v0.md#decision-rules), повтор в двух независимых сессиях — recurring evidence; единичная заминка не запускает изменение продукта. Содержательная неоднозначность требует человеческой математической проверки. Направление выше — кандидат, а не разрешение на реализацию.

Не делать выводов о mastery, переносе, слабости или эффективности обучения по этой сессии. Слова, ответ и скорость не диагностируют причину автоматически. Незакрытый вопрос / требуемое подтверждение: ___________________________________
